# Dependency licenses for this AGPL-3.0 application

Reviewed 10 October 2026. ClaimClock’s code remains **AGPL-3.0-only**. The user authorized the existing dependencies and requested this compatibility assessment. The current release gate checks the exact reviewed lockfile, every non-allowlisted license expression, and the hashes of the distributed third-party notices. It passes this reviewed stack; an unknown license, changed dependency snapshot or missing notice fails the gate. [Machine inventory](../research/dependency-license-audit.json) · [pinned review](../research/license-compatibility.json).

The original three-license policy excluded these additional licenses; that was a project-policy mismatch, not evidence of AGPL incompatibility. Compatibility here means the components can be used in this architecture while preserving their own terms. It does not mean AGPL replaces upstream licenses.

The GPL-2.0-with-font-exception Liberation fonts, optional Foxit fonts, Adobe CMaps and optional PDF decoder binaries are not copied into the site. System fonts are used. Relevant integration notices are still supplied. The build verifies and publishes [source-exact notices](https://claimclock.ketan952.workers.dev/vendor/notices/NOTICE.txt); OCR model provenance is separately pinned. The public repository must supply corresponding source and build scripts for the running release, including future modifications, under AGPL §13. This review covers the locked package graph and identified bundled components, not an independently reproduced native-binary build. Future dependency or distribution changes require a fresh review.
